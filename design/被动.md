# 被动（#住所与娱乐 / #防御 / #商店 / #角色 / #图鉴 / #招募 / #仓库）

> **本文件负责**：七套被动的全部规则 —— 角色上限与上场机制、舒适度、袭击模型与工事、商店与星尘消费、图鉴、招募、仓库与粮仓页面。
> **不在本文件**：工作数值与产出（`工作表.md「工作总览」`）、战斗公式与装备表（`战斗系统.md「角色战斗属性（6 个）」`）、物品清单与价格（`资源表.md「价格规则（金币）」`）、角色名单 / 卡池 / 好感度 / 升星（`角色与抽卡.md「卡池角色（2 位英雄 + 随机普通角色）」`）、主界面与角色页面布局（`界面与交互.md「角色页面」`）。
> **被动 ≠ 工作**：被动**不需要有人入驻、没有进度条、没有精通等级**，买了升级项就常驻生效。工作 33 份（31 常规 + 2 恩赐工作，见 `工作表.md「工作总览」`），被动单列，**不计入工作总数**。

## 一、被动与工作的分界

| 维度 | 工作 | 被动 |
|---|---|---|
| 要角色入驻 | 要 | **不要** |
| 进度条 | 要 | 无 |
| 精通等级 | 有（100 级）| **无** |
| 算不算"工作总数" | 是（33 份）| **不算** |
| 怎么成长 | 分配角色 + 买升级项 | 只买升级项（消耗资源 / 金币）|
| 产出 | 按周期产物品 | 常驻加成（上限 / 效率 / 战力 / 交易）|

七个被动：**#住所与娱乐**、**#防御**、**#商店**、**#角色**、**#图鉴**、**#招募**、**#仓库**。

- **#角色**（第 4 套）：角色页面本身不需要入驻、没有进度条，只做**编队 / 装备 / 查看属性**，符合被动的定义。**角色上限与拖拽上场机制见 §2.3**（它属于「住所与娱乐」）；页面布局见 `界面与交互.md「角色页面」`；角色名单与社交恩赐见 `角色与抽卡.md`。
- **#图鉴**（第 5 套）：收集度系统，纯查看、无入驻无进度条，见 §五。**始终显示**。
- **#招募**（第 6 套）：抽卡 / 卡池 / 角色列表，见 §六。**显示时机 = 发现第一枚招募券的时候**（不是开局）—— 拿到招募券才告诉玩家"这里有抽卡"。
- **#仓库**（第 7 套）：仓库与粮仓的查看面板，两张标签各自显示物品与升级项，见 §七。**开局即显示** —— 仓库从第一天就在用，不需要任何解锁闸门。
- 社交恩赐生成的 **#黑暗之魂 / #模拟纪元** 是**工作**（要入驻、有进度条、有精通），但它们不归"工作"栏，而单列 **「角色特技」栏** —— 见 `界面与交互.md「主界面栏位分类与左侧导航」`。
- **精通是「每个角色 × 每份工作」各一份**：换人入驻**不继承精通**，新角色从 1 级开始。
- 它们和工作升级项共用 v0.0.35 的定价口径（`工作表.md §1.1`）：材料按名字选、第一档便宜、后续档按这套被动的重要性递增；**不再有「4 档阶梯 100 / 300 / 800 / 2,000 + 时代主材料」的统一价格**。

## 二、#住所与娱乐（*语言 解锁）

**设计目标**：把「角色上限」这个核心约束变成一条**要持续投料的成长线**，而不是开局白送的 5 个人。

两条线**抢同一批材料**，玩家每一档只能选一个先买 —— 这就是它的取舍。

### 2.1 角色上限（盖房子）—— 决定实际能上场几个人

**初始可上场 5 人；6 档住房依次 +2/+2/+2/+2/+2/+3，住满正好 18 人。**

- 住房是角色上限的**唯一来源**，没有别的系统能加人数（科技也不再额外加）
- **18 = 最大角色上限**，正好是最后一档「殖民舱」给出的值，任何东西都突破不了

| 档 | 建筑 | 时代 | 价格 | 可上场人数 | 本档 |
|---|---|---|---|---|---|
| （初始）| — | — | — | **5** | — |
| 1 | 茅草棚 | 石器 | 40 木材 + 20 石头 | **7** | +2 |
| 2 | 长屋 | 石器 | 400 木材 + 175 石材 + 75 木板 | **9** | +2 |
| 3 | 石屋 | 中世纪 | 550 石材 + 225 石灰石 + 200 木材 | **11** | +2 |
| 4 | 公寓 | 工业 | 400 混凝土 + 650 钢铁 + 175 玻璃 | **13** | +2 |
| 5 | 住宅区 | 信息 | 900 钛合金 + 350 混凝土 + 250 玻璃 | **15** | +2 |
| 6 | 殖民舱 | 太空 | 1,050 外星合金 + 175 生命维持单元 + 125 精密零件 | **18** | +3 |

- **为什么是 +2**：+2 = 「再开 2 份工作的位置」。每一次扩建都会让玩家重新分配角色，而不是"人数变多、什么都不用改"。
- **最后一档为什么是 +3**：5 + 2×5 = 15，硬顶 18，剩下的 3 个人正好由殖民舱一次性给足，**住满即满编**。
- **为什么要有 18 这条硬顶**：33 份工作 × 平均 1 人远多于 18 人 → **取舍本身就是玩法**。
- **没有舒适度门槛**（v0.0.14 起取消）：舒适度只负责「每点 +0.35% 全局效率」，不再卡住房。
- **v0.0.29 可见性**：住房 / 舒适度 / 工事 / 仓库 / 粮仓的**未购升级项**与工作升级项共用同一条门槛 —— **首次拥有「每种造价资源至少 1 份」之前不显示**（`E.everOwnedAll()`，看 `S.ever` 而不是当前持有量；花掉后仍永久显示）。住房 / 工事 / 仓库 / 粮仓本来就只展开「已完成 + 当前档」，所以效果是：**当前档的造价资源没凑齐过时，这一段暂时不显示卡片**。

### 2.2 舒适度线（家具 / 娱乐 / 地板）

舒适度 **0~100**，由下列升级项相加得到，**硬上限 100（不溢出）**。

```
全局工作效率加成 = 舒适度 × 0.35%      （满舒适度 = 全部工作 +35%）
```

|---|---|---|---|---|

| 2 | 木床 | 石器 | 125 木材 + 65 植物纤维 | +4 |
| 3 | 木地板 | 石器 | 90 木板 + 65 木材 | +4 |
| 4 | 地毯 | 中世纪 | 65 地毯 + 50 布料 + 40 植物纤维 | +6 |
| 5 | 纸窗 | 中世纪 | 75 纸张 + 50 木材 | +5 |
| 6 | 木制家具 | 中世纪 | 125 木板 + 40 铁锭 + 75 木材 | +6 |
| 7 | 石地板 | 中世纪 | 175 石材 + 90 石灰石 | +5 |
| 8 | 台球桌 | 工业 | 150 木板 + 65 塑料 + 40 布料 | +6 |
| 9 | 塑料家具 | 工业 | 350 塑料 + 125 钢铁 | +8 |
| 10 | 瓷砖地板 | 工业 | 275 混凝土 + 150 陶器 + 110 沙 | +6 |
| 11 | 电气娱乐 | 工业 | 90 电子元件 + 75 玻璃 + 65 塑料 | +7 |

| 14 | 全息娱乐 | 信息 | 175 芯片 + 110 铝合金 + 90 玻璃 | +8 |
| 15 | 全息地板 | 太空 | 900 外星合金 + 110 反物质 + 75 精密零件 | +7 |
| 16 | 生命维持舱 | 太空 | 160 生命维持单元 + 1,130 外星合金 + 225 玻璃 | +8 |
| | **合计** | | | **100** |

**舒适度加成怎么控制的**：

- 单项 **+4 ~ +9**，随时代递增，后期项贵但给得多 → 每一代大概 +19~+22 舒适度（约 +7% 全局效率）
- **总上限 100 卡死**，所以后期升级项是"补缺口"而不是"无限叠"
- **+35% 是刻意的上限**：全局倍率乘在 33 份工作上，35% 已经等于整体提速三分之一；再高会让工作自己的升级项失去意义
- 与工作升级项**加法叠加**（工作 +100%，全局 +35% → 该工作 +135%）

**全息地板 / 生命维持舱的价格口径**：按名字取太空材料（外星合金 / 反物质 / 生命维持单元 + 精密零件），不用上千件超织物（≈ 751,500 金）—— 否则舒适度总成本会虚高到百万级，比"把 30 份常规工作全升满"还贵。**v0.0.35 起 16 项合计约 27.7 万金**。

**持续消耗方**（`README.md「数值设计的四条原则」`原则 3 的加强版要求）：舒适度 ≥ 80 时，**陶器 / 地毯 按周期腐坏**（每周期腐坏 10%，用木材 / 布料 / 沙 重新造）—— 装饰不是买一次就完，而是持续开销。

**离线规则**：取"进入离线时的舒适度"，腐坏按天数比例一次算完，**不逐 tick**（腐坏用比例公式，同粮仓）。

### 2.3 角色上限与上场机制

| 项目 | 规则 |
|---|---|
| 上场判据 | 角色列表里的**前 X 名可上场**，**X = §2.1 的角色上限（住房决定，初始 5 → 住满 18）** |
| 上场后 | 可被任何工作选中；可作为**狩猎 / #黑暗之魂 / #模拟纪元**的入驻角色（战斗只在这三处发生）|
| 置灰角色 | **第 X+1 名及之后置灰**：不可上场、不可参战、**不可被任何工作选中** —— 它们就是"待命队列" |
| 拖进前 X | **立即可上场**，工作入驻下拉框里立刻能看到 |
| 拖出前 X（变置灰）| 该角色**自动退出当前工作**（工作回到无人入驻、进度暂停）|
| 待命队列 | 抽到但排在第 X+1 名之后的角色 **不自动入驻**—— 想让谁上场，**必须手动拖进前 X** |
| 待命角色还能做什么| **能收礼物**（好感度与社交恩赐照常推进）、**能正常穿上装备**（12 栏照常换装，装备不浪费）；**但不能参与产出、不消耗食物、不计入基地战力** —— 也不参与其他任何运转计算。**唯一例外**：木易天二人一的 `[潜水摸鱼]`（待命也按自带工作「伐木」产出 50% / 100%，并照常累积他自己的伐木精通）—— 见 `角色与抽卡.md「社交恩赐效果全表」` |
| 上场但闲置的人也吃饭| **只要在场上（前 X 名）就消耗食物**，哪怕没被分配工作 —— "上场 = 养着"，吃饭是占名额的成本；只有置灰的待命队列才不吃饭 |
| 图鉴 | 待命角色**照常计入图鉴**（收集度不受上场限制影响）|
| 操作 | **拖拽是唯一的上场操作**，不需要额外的编队菜单 |
| 改名 | **随时点击名字即可免费改名**|

**关键副作用（这是有意的）**：33 份工作 × 平均 1 人 = 远超上限 → **玩家必须永久做取舍**。和 `科技树.md「工作数量与解锁」` 的结论一致："工作不封顶 ≠ 角色不封顶，取舍本身就是玩法"。

### 2.4 0.35%/点 的验算（v0.0.35 重算）

| 投资线 | 花费 | 买到什么 |
|---|---|---|
| 一份核心工作升满（熔炼 4 档，材料按卖价折算）| ≈ 8.0 万金 | 该工作 **+200%** |
| 30 份常规工作全升满 | ≈ 266.7 万金 | 每份工作 +200%（伐木 / 采矿 +275%；**2 份恩赐工作无升级项**）|
| 舒适度 16 项全买 | ≈ 27.7 万金 | **全部工作 +35%** |
| 住房 6 档全买 | ≈ 28.1 万金 | 角色上限 5 → **18 人** |
| 工事 14 项全买 | ≈ 99.7 万金 | 工事战力 **47,750**、袭击强度 −35% |
| 仓库 6 档全买 | ≈ 29.9 万金 | 仓库 20 → **224 格** |
| 粮仓 3 档全买 | ≈ 2.5 万金 | 腐坏效率 **−100%（不腐坏）** |

> v0.0.35 重设全部升级项材料后重算：工作升级不再统一「100 / 300 / 800 / 2,000」，按升级项名字取材料、核心工作更贵、常规工作更便宜（`工作表.md §1.1`）。金额 = 各档材料 × 物品卖价，逐档数字以 `js/data/jobs.js` / `js/data/passives.js` 为准。
>
> 伐木 / 采矿的工具链（石 → 铜 → 铁）仍是 2 档各 +25%，满级 +275%；其余标准 4 档工作满级 +200%（门槛档只解锁项目、不加产出）。

换算成"等效工作份数"（一份工作的基础产出记作 1）：

- 舒适度 = 0.35 × 30 ≈ **+10.5 份**，每百万金买 **37.9 份**
- 工作升级项 = 每百万金买 **22.5 份**

**结论：0.35%/点 保留。** v0.0.35 的材料重设让舒适度线相对变便宜（旧版约 94 万金），但它仍是一条「不用人、全局生效」的独立成长线，不会替玩家省下工作升级项；后续按实测再调单档数量，不先改百分比。住房 / 工事 / 仓库 / 粮仓都不受这条加成影响。

**设计目标**：给"财富值越高 → 袭击越强"这条压力一个**花钱的出口**，并让防御本身成为一条成长线。

> **工事量级的由来**：基地战力 = **工事 + 上场角色**，角色一侧高出两个数量级（见 §3.2.1），所以工事整体 **×10** 标定，让工事占基地战力的 **12%（石器）~ 52%（太空）** —— 是一条真的有人愿意投的线，而不是被角色淹没的零头。
>
> **工事的职责只有三件**：给工事战力、改袭击强度（-5% / -10%）、耗电。原先那些"战斗用"的特殊作用**全部删除**（瞭望塔的全队命中 +2、护盾塔的给全队加护盾、战斗机器人的失守时优先被击毁）—— 袭击已经是纯数值判定，**工事不该再和狩猎战斗系统挂钩**。

### 3.2 袭击模型

**袭击不是独立战斗玩法，只做「基地战力 vs 袭击强度」的纯数值判定**。

**三条公式**

```
财富值   = Σ(仓库物品数量 × 单价) + 金币
           （只算"会被抢走的东西"。升级项 / 建筑 / 科技 / 工事的花费都不算 ——
             钱已经变成能力了，抢不走；把它们算进去会得到一个只增不减的膨胀项）

本代强度 = 时代基数 × ( 1 + 0.5 × min(财富值 ÷ 时代参考财富, 1) )
           财富值达到参考值即封顶 ×1.5 —— 再囤也不会无限变强

袭击强度 = 上一代上限 + ( 本代强度 − 上一代上限 ) × 时代进度
           上一代上限 = 上一代的 时代基数 × 1.5；石器取 0（从零开始长）

最终强度 = 上式 × 随机(0.95~1.05) × (1 − 工事削减)

基地战力 = Σ(工事战力) + Σ(上场角色战力)
           工事战力 = §3.1 表数值（合计 47,750）
           角色战力 = (生命 + 命中 + 力量 + 防御) × 3 + 装备战力合计（见 §3.2.1）
```

| 时代 | 时代基数 | 时代参考财富 | 袭击强度上限（×1.5）|
|---|---|---|---|
| 石器 | 80 | 50,000 | 120 |
| 中世纪 | 300 | 250,000 | 450 |
| 工业 | 650 | 1,000,000 | 975 |
| 信息 | 1,450 | 4,000,000 | 2,175 |
| 太空 | 3,000 | 16,000,000 | 4,500 |

> **v0.0.20 为什么再砍 90%**：v0.0.17 只降了约 25%，单人新手仍然打不动；这次直接把旧表（800/3,000/6,500/14,500/30,000）整体 ×0.1，并且**删掉早期保护缩放**，公式回到「时代进度插值 → 随机 → 工事削减」三步。100 战力面对的中世纪强度从 1,400+ 降到约 143（1/8 进度）~300（满进度）。

> **`时代进度` 是什么**：本代**科技已解锁数 ÷ 本代科技总数**，从 **0 → 1** 线性成长。它在「**上一代上限**」与「**本代强度**」之间插值 —— 进度 0 时强度 = 上一代上限（石器 = 0），进度 1 时 = 本代强度。
>
> **它解决"跨时代尖峰"**：刚解锁中世纪时，如果强度立刻跳到中世上限 450，而玩家的装备还是石器那套（战力 2,613）→ **一进新时代就被打崩**，而且强度会从 120 直接跳到 450。加了插值，强度随科技进度平滑上升，玩家也随科技拿到新装备 → 威胁与能力同步长大。副作用正好是想要的：**只点科技、不换装备 → 照样挨打**。
>
> 不用新数据：`科技树.md` 本来就有"本代几个科技"这个数。

> **上限封顶是这套模型的关键**：财富值（囤积）是无限的，而基地战力是有顶的（上场 18 人、属性 100 级、装备到顶）。不封顶的话终局必失守 —— "装备跟得上时代就能轻松抵抗"这句需求的前提就是封顶。**财富值本身怎么防膨胀、时代基数 / 参考财富怎么定，见 §3.2.3 / §3.2.4。**

```
袭击强度 ≤ 基地战力  →  击退：无损失（可能给一点战利品）
袭击强度 >  基地战力  →  失守：资源被抢 + 工事被拆（要按 30% 造价修复）+ 角色重伤
```

| 项目 | 规则 |
|---|---|
| 有没有战斗界面 | **没有** —— 挂机被袭击时玩家通常不在场，**离线不能惩罚没看屏幕的人** |
| 谁参与 | **不派角色应战**，但**上场角色的战力计入基地战力**（属性 + 装备，见 §3.2.1）；待命队列不计 |
| 人数修正 | 石墙 / 钢筋混凝土墙 / 合金要塞 的「**袭击者入场人数 -1**」改为**降低袭击强度**（每档 **-10%**，三档共 -30%）|
| 尖木陷阱 | **袭击强度 -5%**（纯数值模型里没有"首个敌人"）|
| 时代进度 | 本代**科技已解锁数 ÷ 本代科技总数**（0 → 1），在「上一代上限」与「本代强度」之间**插值** —— 防"刚进新时代就被新上限打崩"，见 §3.2.4 |
| 失守被抢 | 仓库物品与金币**各按 10% 数量**被抢（不是全没）—— 抢完财富值下降，强度自动回落（负反馈，见 §3.2.3）|
| 战报 | 一份**纯文本结算**（谁打过来、强度多少、基地战力多少、损失清单），不需要模拟过程 |
| 情报商品 | 商店 ④情报 卖"下次袭击的时间与规模" —— 用来**提前判断要不要紧急补工事** |
| 触发周期 | **每 2 小时判定一次**，强度 `×0.95~1.05` 随机 |


**为什么这样就够了**：袭击的用途只有一个 —— **给财富值一条压力**，逼玩家把资源投进防御。纯数值判定完全够用，而且天然满足"离线优先"。

#### 3.2.1 角色战力与装备战力

**角色属性直接换算成战力；装备自身额外带一份战力数据**。

```
单角色战力 = (生命 + 命中 + 力量 + 防御) × 3 + 装备战力合计

装备战力   = 伤害减免% × 5 + 力量值 × 2      （防具 / 衣物 / 盾牌）
武器战力   = 力量加成 × 2 + 命中加成 × 1      （主手武器）
```

- **属性四项各 1~100 级**（`战斗系统.md「角色战斗属性（6 个）」`）→ 单角色属性部分最高 **1,200**
- **装备战力按件相加**，共 12 栏；**温度 / 护盾值不计战力**（它们服务狩猎，不服务袭击）
- **伤害减免按装备原始值合计**（不被 80% 上限截断）—— 否则太空套的 DR 被截到 80% 后装备战力会失真
- **只有「上场角色」计入**（前 X 名，X = 角色上限，由住房从 5 推到 18）：待命队列不计，这也让"拖谁上场"多了一层含义
- 装备战力是**数据字段**：可按上式逐件算，也可逐件手填（数值口径见 §3.2.2）

> **为什么这样就够**：它把「练属性」和「换装备」两条已有成长轴直接接进防御，不需要新系统。

#### 3.2.2 五档满装基线（"轻松抵抗"的验算）

假设每个上场角色都**练到本时代该有的属性、穿满本时代最好的一套**：

| 时代 | 属性（四项各）| 单角色战力 | 上场人数 | 角色战力 | 工事战力 | 基地战力 | 袭击强度上限 | 富余 |
|---|---|---|---|---|---|---|---|---|
| 石器 | 10 | 257 | 9 | 2,313 | 300 | 2,613 | 120 | **21.8×** |
| 中世纪 | 25 | 717 | 11 | 7,887 | 1,550 | 9,437 | 450 | **21.0×** |
| 工业 | 45 | 1,168 | 13 | 15,184 | 6,250 | 21,434 | 975 | **22.0×** |
| 信息 | 65 | 1,758 | 15 | 26,370 | 20,750 | 47,120 | 2,175 | **21.7×** |
| 太空 | 85 | 2,464 | 18 | 44,352 | 47,750 | 92,102 | 4,500 | **20.5×** |

**读法**：

- **装备跟得上时代 → 富余约 20~22 倍**，再加石墙三档的 **-30%**，实际是 **约 30 倍** → "轻松抵抗"成立
- **装备落后一个时代 → 角色战力约掉一半**，但仍有约 10 倍富余 → 当前版本优先让玩家不卡关，落后惩罚要等后续调参
- **完全不练属性、不换装备**（只靠工事）→ 终局仍能靠工事顶住；这是 v0.0.20 有意放宽的结果
- **双手武器少一件副手**：本表按「1H 武器 + 盾」的满装口径算；双手武器少掉的盾战力由更高的武器力量补偿，`一键最优` 会按「主手 + 副手合计战力」自动比较，不会盲目选双手

**每档"满装一套"的装备战力**（公式同上，由 `模拟/口径校验.py` 逐件现算）：石器 **137** / 中世纪 **417** / 工业 **628** / 信息 **978** / 太空 **1,444**；黑魂套 4 件 **646**（信息偏上档）。逐件数值见 `资源表.md`。

#### 3.2.3 财富值：挂机时为什么不会无限膨胀

**先说结论：财富值这个数字会一直涨，这没关系 —— 要管的是"它涨了会影响什么"。**

| 层 | 机制 | 作用 |
|---|---|---|
| 1 | **饱和输入** | 公式里写的是 `min(财富值 ÷ 参考财富, 1)` —— 涨到参考财富以上，对强度的影响**恒为 ×1.5**；再涨 100 倍也还是 ×1.5 |
| 2 | **只算可被抢走的量** | 升级项 / 建筑 / 科技 / 工事的花费**不进财富值** → 去掉两个**单调不减**的膨胀项，财富值变成真正的"囤积存量" |
| 3 | **失守即回落** | 失守抢的是仓库物品与金币 → **财富值随之下跌，强度自动回落**。这是天然负反馈：袭击会把囤积削回安全线，然后自己停下来 |

**必须写死的纪律**：财富值**只能作为饱和输入出现** —— **永远不做分母、不做乘数、不做开方指数**。以后任何新公式要用财富值，先套一层 `min(财富值 ÷ 参考财富, 1)`。

**几个边界要说清**：

- **粮仓（食物）算财富值** —— 它是可被抢走的实物。粮仓类 17 种会腐坏，这本身已是一条自然消耗
- **金币算，且是唯一"零成本无限囤"的项** —— 但卖物品换金币是**等值交换**（物品少多少、金币多多少），财富值不变，所以不构成刷分手段
- **穿在身上的装备不算、放仓库里的备用装备算** —— 抢不走的不算囤积
- **"财富值涨到参考财富以上"不该被惩罚** —— 玩家正常玩、收入高，本来就该超过参考线；封顶的作用是**让它不再有影响**，不是罚他

#### 3.2.4 时代基数 / 参考财富怎么定

**旧表整体 ×0.1，不再按满装基线现算：**

```
时代基数 = 旧表（800 / 3,000 / 6,500 / 14,500 / 30,000）× 0.1
        = 80 / 300 / 650 / 1,450 / 3,000
```

| 时代 | 本代满装基地战力 | 时代基数 | 反推出的富余 |
|---|---|---|---|
| 石器 | 2,613 | **80** | 21.8× |
| 中世纪 | 9,437 | **300** | 21.0× |
| 工业 | 21,434 | **650** | 22.0× |
| 信息 | 47,120 | **1,450** | 21.7× |
| 太空 | 92,102 | **3,000** | 20.5× |

**v0.0.20 的调整**：
1. 时代基数整体 ×0.1（旧表 800/3,000/6,500/14,500/30,000 → 80/300/650/1,450/3,000），袭击强度上限同步降到 120/450/975/2,175/4,500。
2. **删除 v0.0.17 的早期保护系数**：不再按基地战力缩放，强度只由「时代基数 × 财富 × 时代进度 × 随机 × 工事削减」决定。

**所以真正要拍的只有两个量**，而它们都由别的表推出，**不是新的自由参数**：

1. **本代"该有的"角色属性**（10 / 25 / 45 / 65 / 85）—— 由 `战斗系统.md` 的属性成长速度决定
2. **本代上场人数**（9 / 11 / 13 / 15 / 18）—— 由 §2.1 的住所上限表决定

**v0.0.20 起时代基数固定为旧表 ×0.1，不再随基线重算**；如果之后要动属性/人数基线，先决定是否回到「按满装战力推导」的口径。

**时代参考财富（= "囤到多少算真囤积"）的锚点：**

```
时代参考财富 ≈ 本代"非花不可"的总支出
             = 本代科技 + 建筑 + 升级项 + 全队装备的总造价
```

正常玩家会把这笔钱花掉（花掉就不进财富值了）→ **只有真在囤的人才会触到参考财富**。现表里的 5 万 / 25 万 / 100 万 / 400 万 / 1,600 万是按 `README.md「工作与精通」`的收入曲线（≈2 → 90 金/秒）估的中位数，**等 `资源表.md` 汇总出本代总造价后回填**。

### 3.3 它怎么接进数值系统

- **战力是算出来的，不是打出来的**：工事战力 + 上场角色战力直接相加，不跑 `simulate()`
- **花钱 = 降财富值**（升级项 / 建筑 / 科技 / 工事的花费都不进财富值）→ 投资任何成长线都顺带降低袭击压力
- **被拆的工事不会自动重建**，修复价 = 建造价 × 30%
- 防御耗电 **18 瓦**（峰值 38 → **56 瓦**），供给方案见 `工作表.md「电力系统」`

## 四、#商店（*文字 解锁）

### 4.1 金币

- 金币**只能靠卖出获得**（不能买），**不占仓库格**
- **卖出价 = 物品的价值**（价格表见 `资源表.md「价格规则（金币）」`）
- **买入价 = 卖出价 × 3** → 买低卖高不成立；**技能书也一样（卖出 8,000 / 买入 24,000）**。**不刻意回避"洗钱"**，后期用**财富值**调控经济也是设计手段
- **材料口径**：装备表统一写「皮革」、不区分种类（价格表统一 3 金/个）—— 见 `资源表.md「价格规则（金币）」`

### 4.2 货架

货架固定 **6 格**，每 **60 秒**刷新一次。**商店不占用角色**。

| 格 | 内容 |
|---|---|
| 1~5 格 | **随机商品**：从已解锁品类池里随机抽**物品 + 随机数量** |
| 6 格 | **固定卖招募券**（永远刷新，不随机）|

- **随机池不含装备 / 武器** —— 装备只能自己造，商店不卖战利品
- 抽到**精通技能书**时数量固定 **1 本**，且书是低权重稀有格
- **精通技能书与升星药水另有「常驻商品」卡片入口**（带图标，见 §4.4 / §4.7），不受 60 秒刷新影响；货架与常驻卡片上的物品**悬停都能看物品面板**
- **点击任意一格 → 弹窗确认**（弹窗显示：物品、数量、单价、总价）→ 点确认才扣金币，误点不会买东西
- 第 6 格存在的意义：角色是最稀缺资源，**招募券必须有稳定的金币下限出口**，不能只靠"极低概率产出"赌

### 4.3 能买到什么

商店的定位：**把过剩的形态换成稀缺的形态，再买情报** —— 不是资源增量，也不是绕过角色上限的捷径。

| 品类 | 内容 | 为什么值得存在 |
|---|---|---|
| ① 稀有矿 | 铀矿 / 稀土 / 金（按时代解锁）| 采矿是概率抽签，卡概率的痛点只能用钱解决 |
| ② 商队专属材料 | 超织物 / 外星皮革 | 给"只能买"的材料一个身份（RimWorld 的超织物就是贸易品）|
| ③ 招募券 | 召唤角色（**占第 6 格**）| 角色是最稀缺的资源，金币的最终出口 |
| ④ 情报 | 下次袭击的时间与规模 | 唯一的"预判"手段，与 #防御 配对使用 |
| ⑤ 形态转换 | 直接买 混凝土 / 钢铁 / 精密零件 | 把囤积的粮食、木材换成建材，解决"上游积压" |
| ⑥ 精通技能书 | 31 本，一本 +10 精通等级 | **终局最大的金币出口**：钱换在岗时间，不换产能 |

### 4.4 精通技能书

| 项目 | 规则 |
|---|---|
| 数量 | **31 本**（《伐木精通书》…《曲速核心制造精通书》，**31 份常规工作各 1 本；不覆盖 2 份恩赐工作**）|
| 效果 | 读完该角色**该工作精通等级 +10 级** |
| 价格 | **24,000 金 / 本**（固定价，推导见 `资源表.md「精通技能书」`）|
| 解锁 | **商店开张（*文字，中世纪）即可买**；**已解锁工作**的精通书全部以常驻卡片展示（带图标）—— 前期看得见、买不起 |
| 仓库 | **正常占用 1 个仓库格**（不再豁免）|
| 卖回 | **可正常卖出**：卖出价 **8,000 金**（= 24,000 ÷ 3，正好符合「买入 = 卖出 × 3」）|
| 洗钱 | **不回避** —— 买进再卖回直接亏 2/3，"买低卖高"本来就不成立；经济由**财富值 / 袭击值**在后期调控 |
| 上限 | 每份工作吃 10 本即满级（100 级）；**已满级时弹窗要给警告**，避免浪费 24,000 金 |

**为什么是"固定价 + 越高越划算"**：一本书恒定 +10 级，但它替玩家省下的**在岗时间**随等级陡增：

| 阅读时机 | 跳过的等级 | 省下的在岗时间 | 折成劳动价值（0.5 金/秒）|
|---|---|---|---|
| 开局（1→10 级）| 1~10 | **171 秒** | 85 金 |
| 中期（41→50 级）| 41~50 | **814 秒** | 407 金 |
| 后期（81→90 级）| 81~90 | **3,029 秒** | 1,515 金 |
| 收尾（91→100 级）| 91~100 | **4,222 秒** | 2,111 金 |

- 固定 24,000 金 = 最贵的 **10 级（4,222 秒 ≈ 70 分钟）劳动价值的 11.4 倍**、开局 171 秒的 141 倍
- **所以玩家自然会等到后期才买**：前期买是烧钱，90 级买才是"用钱换 70 分钟"。不需要额外机制去拦前期消费
- 全买 310 本 = **744 万金**（终局金币的主要去处）

### 4.5 防刷子（五条）

1. **买 3× 卖** → 无套利空间
2. 库存 **6 格**，**60 秒**刷新一次
3. **挂卖单占库存格** → 不能一次卖空
4. 同一物品**连续卖出回收价 × 0.9**（下限 20%）
5. **总交易额 ≤ 财富值 × 2**（每小时）

### 4.6 解锁闸门

商店只有一个开关，开了就全开：

| 项目 | 规则 |
|---|---|
| 开张 | ***文字（中世纪）** 解锁商店 |
| 货架 | **固定 6 格**，不随任何进度增长 |
| 品类 | **①②③④⑤⑥ 全部随商店开张解锁** |
| 第 6 格 | **招募券**，永远刷新 |

## 五、#图鉴（第 5 套）

**收集度系统，始终显示。** 参考梅尔沃放置的「图鉴 / 完成情况」：一个只读的收集面板，回答"这个世界还有什么我没见过"。

### 5.1 结构

| 标签页 | 收录什么 | 未发现时 |
|---|---|---|
| **物品** | 全部 **206 种**物品（**212 − 6 件随黑暗之魂线隐藏的：灵魂 / 余火 / 黑魂套 4 件**）| 显示 **？** + 灰色图标占位 |
| **敌人** | 全部 **22 种**敌人（18 普通 + 4 模拟纪元怪；4 只黑魂怪随黑暗之魂线隐藏）| 同上 |

| （可扩展）| 区域 / 科技 … | — |


### 5.2 发现规则

- **获得过 / 遭遇过 / 拥有过一次** → 永久记为已发现（卖光、打光**不回退**）
- 抽卡抽到角色（哪怕进待命队列）→ 计入角色页
- 恩赐怪要先解锁对应社交恩赐才会出现
- **首次发现即触发「收录奖励」**，见 §5.5

### 5.3 点开详情显示什么

| 标签 | **必定显示** | 额外显示 |
|---|---|---|
| **物品** | **图标 + 名称** | **价格**（卖出 / 买入）；**若是装备 → 属性**（栏位 / 伤害减免 / 力量；武器 → 力量 / 命中 / 间隔）|
| **敌人** | **图标 + 名称** | **战斗属性**（HP / 命中 / 力量 / 防御 / 伤害减免 / 攻击间隔）+ **掉落物**；**可畜牧的敌人额外显示 图鉴认知度进度 + 畜牧产物** |
| **角色** | **图标 + 名称** | **战斗属性** + **好感度**（0~100 与 25/50/100 三个节点）+ **社交恩赐**（`[XXX]` / `[XXX+]`，未解锁显示"未解锁"）；随机普通角色标注「随机普通角色 / 无社交恩赐」|

### 5.4 完成情况（Melvor 式）

- 每个标签各有一个**完成度**：`已发现 / 总数`（如 物品 137/206、敌人 15/22、角色 1/2）
- 面板顶部有**总完成度**（三标签加权或合计，实现时定）
- 完成度**本身不给奖励** —— 奖励挂在「首次收录」的领取按钮上（§5.5），完成度仍是目标指示器。

### 5.5 收录奖励（v0.0.10 新增）

| 条目 | 首次收录奖励 |
|---|---|
| **物品** | **招募券 ×1** |
| **敌人** | **招募券 ×3** |
| **角色** | **招募券 ×5** |

- 未领取的条目：**金色边框** + 右上角**「领取 +N」**按钮（物品卡 / 敌人表格行 / 角色卡都适用）。
- 页头只要还有未领奖励就显示 **「全部领取 · N 项（+M 招募券）」**，一键领完；领完按钮消失。
- 每个条目**终身一次**，领取状态存 `S.codex`（`{items,enemies,chars}`），读档 / 刷新不重复发。
- 敌人表格因此多出**「奖励」**列（未收录时为 `—`）；已收录但未领取的行整行泛金。

## 七、#仓库（第 7 套）

**开局即显示**，不做解锁闸门 —— 仓库从第一天就在用。**纯查看面板 + 升级项**：无人入驻、没有进度条、没有精通，买升级项即常驻生效，符合被动的定义。

页面分**两张标签**，各自都有「物品」与「升级项」两块：

### 7.1 标签：仓库

| 区域 | 显示什么 |
|---|---|
| 顶部 | **已占格 / 总格数**（如「62 / 88 格」）|
| 物品列表 | 每格一行：图标 · 名称 · **数量** · **单价** · **总价值**；按「时代 → 类别」分组，顺序与 `资源表.md` 一致 |
| 排序 | 两种：**按名称** / **按总价值**。不做筛选 |
| 升级项 | **6 档仓库扩容**，每档一张卡：效果（**+34 格**）、所需建材、当前是否够。建材按升级项名字取（木头仓库 = 木材 + 石头，石头仓库 = 石材 + 木材，金属仓库 = 铁锭 + 石材 …），逐档数字见 `js/data/passives.js` |

### 7.2 标签：粮仓

| 区域 | 显示什么 |
|---|---|
| 顶部 | **当前份数**（粮仓容量无限，不显示上限）+ **还能撑多久**（"812 份 · 4 分 31 秒"）+ 一行「容量无限 · 腐坏 每 600 秒减半」|
| 物品列表 | 17 种粮仓类（14 种食材 / 种子 + 3 种熟食）各一行：图标 · 名称 · 数量 · **腐坏** |
| 腐坏提示 | 腐坏一列只标状态（`腐坏中` / `不腐坏`）；具体「每 N 秒减半」写在顶部那一行，基础半衰期 600 秒 |
| 升级项 | 三档只改腐坏效率：**[陶器]** −30%、**[地窖]** −60%、**[冷库]** −100%（完全不腐坏）。容量无限，升级项不再提供容量、也不再提供仓库格数 |

> **粮仓容量与腐坏口径（v0.0.35）**：容量无限，生产多少收多少；腐坏对粮仓里所有食物统一生效 —— 基础每 **600 秒减半**，买到的最高档按 `spoilMul` 把腐坏效率整体拉低（陶器 ×0.7 → 有效半衰期约 857 秒；地窖 ×0.4 → 1500 秒；冷库 ×0 → 永不腐坏）。腐坏损失的 15% 转成堆肥，进仓库。

> **堆肥不在这页**：腐坏产出的 **堆肥** 是**仓库物品**（占用 = 仓库），在**仓库标签**里按普通物品列，不在粮仓里单独占一行。

### 7.3 只装占格的，不装数值

- **仓库与粮仓两页都只列占格物品**：仓库标签列「占用 = 仓库」的 194 种，粮仓标签列「占用 = 粮仓」的 17 种（口径见 `资源表.md「口径」`）。
- **金币 / 科研点 / 电力 / 食物是数值不是物品，一律不进这两页** —— 它们在**主界面顶栏资源条**常驻显示（见 `界面与交互.md「顶栏资源条」`）。
- **只查看，不买卖**：卖出与买入都在 `被动.md「#商店」`，仓库页不提供交易入口（避免两处都能卖）。
- **数量为 0 的物品不占行**：未发现过的物品**不显示**，避免开局就列出 200 多条空条目、也避免剧透下一代的材料。
- 升级项的显示条件与所有升级项一致（v0.0.27）：**「解锁条件」+「首次拥有 1 份每种所需资源」**双满足后**永久显示**；不再看当前持有量，花掉 / 卖掉材料也不会消失（见 `科技树.md「设计原则」`）。
