# 资源表（所有占用仓库 / 粮仓格的物品）

> **本文件负责**：物品清单与价格、物品用途反向索引、仓库格数、**价格推导规则**。
> 凡占用仓库格 / 粮仓格的物品，都在本文件里能查到 —— 这是**唯一权威**的物品清单。
> **不在本文件**：仓库 / 粮仓机制与扩容档位 → `README.md「仓库」`、`README.md「粮仓与保质期」`；工作产出与配方 → `工作表.md「产出清单与配方」`；升级项名称与解锁 → `工作表.md「通用规则与升级项定价公式」`、`科技树.md`；武器栏位与战斗效果 → `战斗系统.md`；敌人分布与掉落 → `敌人表.md`。

## 一、怎么用这张表

### 1.1 口径

- 表里的 **金币** 列 = **卖出价**，买入价 = 卖出价 × 3；完整公式、取整规则与例外见 §十。
- 占用列只有两种：**仓库**（194 种）与**粮仓**（18 种，会腐坏）。
- **不占格的数值不在这张表里**：金币 / 科研点 / 电力 / 食物是**数值不是物品**，在**主界面顶栏资源条**显示（见 `界面与交互.md「顶栏资源条」`）；本表只收「占用 = 仓库 / 粮仓」的物品。
- **仓库页也照这个口径**：仓库标签只列「占用 = 仓库」的，粮仓标签只列「占用 = 粮仓」的（见 `被动.md「#仓库」`）。
- 物品总数 **212 种**，构成与格数推导见 §九。

### 1.2 设计顺序

1. **先定物品表**（本文件）→ 得出物品种类总数
2. **再用种类总数定仓库格数** → 终局格数（见 §九）
3. **最后定仓库扩容档位** → 每个时代的新建筑材料 = 一次质变扩容

顺序不能反。先定格数再填物品，必然要反复改。

### 1.3 校验

`模拟/口径校验.py` 每次运行会重算三件事：

- 每个物品的来源是否真有配方（配方以 `工作表.md「产出清单与配方」` 为准）
- 逐件装备战力与每代「满装一套」合计（见 §十）
- 物品总数与仓库格数（见 §九）

### 9.2 终局格数的推导

**194 种占用仓库** → 想让玩家能把所有东西都留着，需要 ≥194 格。留约 15% 余量应对后续扩充 → **224 格**。

配合 **6 次**阶段式扩容，每次 **+34 格**（20 格为初始）：

```
初始 20 → 木头仓库 54 → 石头仓库 88 → 金属仓库 122
        → 钢筋混凝土仓库 156 → 合金仓库 190 → 量子仓库 224
```

- 6 次扩容的**升级项名称 / 解锁 / 建造材料** → `README.md「仓库」`（权威）+ `科技树.md`；本文件只负责「物品数 → 格数」。
- **为什么这样设计**：每个时代的核心新材料既是「解锁条件」又是「建造材料」，所以拿到新材料的瞬间就获得一次仓库质变。玩家感受到的是「进入新时代 → 仓库翻新」，而不是「一直在点 +1 格」。
- **注意**：地窖与冷库**不提供仓库格数**，它们只负责粮仓（容量 + 半衰期）→ `README.md「粮仓与保质期」`。

## 十、价格规则（金币）

> 每种物品的 **金币** 列已直接写在 §二 矿石表 + 各时代的表里（材料 65 + 装备 57 + 武器 28 + 粮仓 18 = **168 种**）。
> **卖出价 = 表里的金币值**（结算时向下取整，可以为 0：单卖 1 份食材 = 0 金，10 份 = 1 金）；商店买入价 = 该值 × 3。
> **例外**：31 本**精通技能书**（§十一）、4 档**好感度礼物**与**升星药水**（§十二）是商店 / 抽卡专属物品，价格单列。

```
劳动费率        = 0.5 金币 / 秒          （一个工作周期秒数 × 0.5）
采集类（无输入）  = 周期 × 0.5，按每次产出摊到每个物品
采矿（概率抽签）  = 基准票 1.5 金（3 秒 × 0.5）
                   单矿价值 = 1.5 × (100 ÷ 该矿权重)，不取整
                   （石油 / 硝酸 / 铝土矿 / 钛矿 由下游配方反推，不走这条）
加工品          = Σ(输入价值 × 数量) + 周期秒数 × 0.5
装备 / 武器      = 造价材料价值合计 × 1.5（工艺附加值 50%）
更先进的同配方冶炼（钢铁）= 同配方 × 1.5
通用「皮革」按 3 金/个计（装备表未区分皮革种类）

装备战力（新增，服务 #防御 袭击判定）= 伤害减免% × 5 + 力量值 × 2
武器战力（同上）                = 力量加成 × 2 + 命中加成 × 1
```

**锚点**：1 木材 = 1 金币（伐木 2 秒 × 0.5 金/秒）。

**采矿价的反证**：铁锭 18 = 2 × 7.5 + 1 木材 + 4 秒 × 0.5；金锭 78 = 2 × 37.5 + 1 + 2；银锭 41 ≈ 2 × 18.75 + 1 + 2。

**装备战力怎么用**：它**不影响金币**（金币只看造价），只接进 `被动.md「#防御」` 的基地战力。按上式逐件可算，所以五张装备表的每一件都**不用手填**；每代「满装一套」合计 = 石器 137 / 中世纪 417 / 工业 628 / 信息 **978** / 太空 **1,444**（由 `模拟/口径校验.py` 逐件现算，改装备后跑一次即可）。

**三个要读懂的后果**：

1. **金锭 78 / 银锭 41 = 高价值出售品** —— 金银的用途就是卖钱
2. **精密零件 347 > 芯片 110.5** —— 太空装备大量吃精密零件，工业 / 信息时代的中间品到终局仍然值钱
3. **超织物 / AI 核心 / 生命维持单元 都是 751.5**（同一配方三个产出）—— 太空时代最贵的可交易物

## 十一、精通技能书（31 本，商店消耗品）

- **来源**：只在商店卖（随机格低权重 + 恒定 1 本），不可制造。
- **效果**：读完让**该角色**在**对应工作**上的精通等级 **+10 级**（精通是「角色 × 工作」各一份，见 `README.md「工作与精通」`）。

### 11.1 定价推导（写死，实测后可调）

```
一本 = +10 级，跳过的最贵 10 级（91→100 级）
     = 14,394 − 10,172 = 4,222 秒在岗时间
     = 4,222 × 0.5 金/秒 = 2,111 金（劳动价值）
定价 = 2,111 × 11.4 ≈ 24,000 金   ← 11.4 倍溢价是刻意留的"奢侈品系数"
```

| 阅读时机 | 跳过的等级 | 省下的在岗时间 | 折成劳动价值 |
|---|---|---|---|
| 开局（1→10）| 1~10 | 171 秒 | 85 金 |
| 中期（41→50）| 41~50 | 814 秒 | 407 金 |
| 后期（81→90）| 81~90 | 3,029 秒 | 1,515 金 |
| 收尾（91→100）| 91~100 | **4,222 秒（70 分钟）** | **2,111 金** |

**三条要读懂的性质**：

1. **前期解锁但买不起**：石器时代全队收入 ≈2 金/秒 → 一本要 **3.3 小时**总收入；终局 ≈90 金/秒 → 一本 ≈4.5 分钟
2. **固定价 + 越高越划算 → 玩家自然后期买**：开局读一本只省 171 秒（85 金）却花 24,000，等于烧钱；90 级读一本省 70 分钟。**不需要策划去拦前期消费**
3. **它是终局金币出口，不是省钱手段**：买书永远亏"劳动价值"（11.4 倍溢价），换来的是**在岗时间** —— 而 124 小时的全精通在岗时间，正是本项目最长的长尾
