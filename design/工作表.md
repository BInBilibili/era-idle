# 工作表（33 份工作：31 常规 + 2 恩赐工作）

> **本文件负责**：33 份工作的消耗 / 产出基数 / 进度条 / 升级项价格与档位 / 采矿权重与概率 / 电力数值。
> **不在本文件**：物品价格与用途 → `资源表.md「价格规则」`；工作解锁所依赖的科技 → `科技树.md「工作数量与解锁」`；战斗公式与武器表 → `战斗系统.md「各时代武器全表」`；敌人分布与掉落 → `敌人表.md「掉落物规则」`；恩赐工作与角色 → `角色与抽卡.md「两份恩赐工作」`。
> **时间基准**：tick 200ms，**1 天 = 24 秒**（1 秒 = 1 小时，`README.md「时间机制」`）。
> **⚡ = 耗电**：瓦是**每秒的持续功率**。工作在**运转中（有人 + 有料 + 有电）**才按秒计入，撤人 / 缺料 / 缺电立刻不计 ——「机械加工 0.4 瓦」= 每秒 0.4 瓦，**不是每次行动扣 0.4**；升级项的 +1 瓦同样只在运转时计入。**每个 ⚡ 升级项统一 +1 瓦**（逐条写在各工作的 ⚡ 行，汇总见 §11）。
> **🎯 精通速度加成**：各工作的「进度条」是**基础周期**；实际周期 = 基础周期 ÷ (1 + 0.01 × ⌊精通等级 ÷ 10⌋)，**满级 100 级 = +10% 速度**。精通是「角色 × 工作」各一份（`README.md「工作与精通」`），同一份工作换角色入驻实际周期不同。**产出基数不因精通改变，本表数字就是基数。**

## 一、通用规则与升级项定价公式

### 1.1 升级项定价（v0.0.35 重设）

v0.0.27 ~ v0.0.34 用「4 档统一阶梯」（100 / 300 / 800 / 2,000 + 固定辅材），结果 114 档升级项长得一模一样：第 2 档永远是 300 主材，材料也跟升级项名字无关。**v0.0.35 全部重设**，改成「按名字选材料 + 按该工作项目的重要程度定量」：

1. **材料只取现有物品**（`资源表.md` 的仓库 / 粮仓清单），按升级项名字挑同类材料：
   - 工具 / 武器：木材 + 对应金属（石斧 = 木材 + 石头；铜斧 = 木材 + 铜锭；铁斧 = 木材 + 铁锭）
   - 小屋 / 牧场 / 围墙：木材 + 石材 / 石灰石
   - 窑 / 炉 / 陶器 / 玻璃：沙 + 石材 + 木材
   - 发电机 / 电力设备：钢铁 + 铜锭 + 机械零件（按设备名再加硅片 / 核燃料）
   - 电子 / 太空设备：钛合金 / 外星合金 + 芯片 / 精密零件 / 反物质
2. **第一档（解锁项目 / 进门档）必须便宜**：只用开局能拿到的材料，6~70 件，总价 ≤ 5,000 金，且不超过第二档的 40%（石斧 / 石镐 = **6 木材 + 4 石头**；门槛档里最贵的环形加速器也才 3,541 金）。
3. **后续档按「该工作全部项目的重要程度」决定数量**：同档位下，**核心工作**（伐木 / 采矿 / 种植 / 烹饪 / 熔炼 / 科研 / 电力）数量与总价最高，**重要工作**（采集 / 畜牧 / 加工 / 切石 / 制陶 / 锻造 / 木工 / 机械加工 / 化学精炼 / 石油开采 / 玻璃 / 火药 / 半导体 / 精密装配 / 外星采矿 / 粒子对撞 / 合成）居中，**常规工作**（医疗 / 纺织 / 裁缝 / 编织 / 造纸）最低。便宜材料（木材 / 石头 / 沙）可以放到上千件，贵材料（钢铁 / 钛合金 / 精密零件 / 外星合金）只放几十到几百件，但凑出来的总价仍按这个次序 —— 例：核心工作终档主材约 1,000~3,500 件，常规工作终档约 600~1,100 件。
4. **同一份工作内，每一档的材料种类与数量都不重复**；跨工作的同档也不再共用同一组数字，凑料时一眼能看出差别。
5. **门槛档仍然 `bonusPct = 0`**、只负责解锁项目；⚡ 档仍然 **+1 瓦**（不进价格）。
6. 大多数工作 **4 档**；**伐木 6 档、采矿 8 档、电力 5 档**；信息 / 太空多数工作只有 2~3 档。
7. **链式升级（只此两处）**：伐木 / 采矿的第 1 档不是「三选一」，而是**石 → 铜 → 铁**三连：石斧 / 石镐（**不加产出，只解锁项目**）→ 买完才显示铜斧 / 铜镐（+25%，需 *金属冶炼 240）→ 再买完才显示铁斧 / 铁镐（+25%）。铜 / 铁两档**各自 +25%、可叠加**，所以这两份工作的工具线合计 **+50%**，满级总加成 **+275%**；其他标准 4 档工作满级 **+200%**（第 1 档 0%）。
8. 逐档的最终材料与数量**以 `js/data/jobs.js` 的 `upgrades[].cost` 为准**，本文件各工作小节的表已同步同一组数字；被动升级项（住房 / 舒适度 / 工事 / 仓库 / 粮仓）走同一套规则，见 `被动.md`。

**历史沿革**（保留结论，数值已作废）：
- **v0.0.27**：石斧 / 石镐从「100 木材 + 50 石头」下调为开局第一把工具；升级项显示条件从「持有 ≥30% 材料」改为「**首次拥有 1 份每种所需资源后永久显示**」。
- **v0.0.29**：石斧 / 石镐描述改为「解锁伐木项目 / 解锁采石项目」且 `bonusPct = 0`；三处「小屋」升级（伐木小屋 / 采矿小屋 / 采集小屋）的辅材由 **石头** 改为 **石材**。
- **v0.0.30**：除「采集」外，每份常规工作都必须先买第 1 档升级项，第一批项目才会出现；并审计掉「第 1 档要本工作自己的产物」的死锁（熔炼 / 半导体 / 外星采矿 / 粒子对撞）。
- **v0.0.31**：所有门槛档 `bonusPct = 0`，只负责解锁项目（采集的采集篮例外，仍 +25%）；门槛档说明由 `Engine.upgradeDesc()` 从项目名生成。
- **v0.0.35**：废弃「4 档统一阶梯」与「主材按时代走」两条旧口径，改为本节的按名字 / 按重要程度定价。

### 1.2 产出基数的推导（1 个工人喂饱几个下游工人）

| 上游 | 速率 | 下游 | 速率 | 结论 |
|---|---|---|---|---|
| 伐木 2 秒 3 木材 | 90 木材/分钟 | 加工 3 秒 2 木材 | 40 木材/分钟 | **1 个伐木工喂 2.25 个加工工** → 加工通常只有 1 个 |
| 采矿 3 秒 1 矿（石头基准）| 20 矿/分钟（石头）| 熔炼 4 秒 2 矿 | 30 矿/分钟 | **1.5 个采矿工喂 1 个熔炼工** |
| 采集 3 秒 1 资源包 | 20 件/分钟（平原 40% 是食物、草地 90% 是植物纤维） | 烹饪 2 秒 4 食材 | 120 食材/分钟 | 不再按旧口径 1:0.5；食物主要改由种植 / 狩猎供给 |
| 种植 3 秒 6 作物 | 120 食材/分钟 | 烹饪 2 秒 4 食材 | 120 食材/分钟 | **1 个种植工需 1 个烹饪工** |

**验收区间 0.5~2**（上游 → 下游的工人配比）：

| 上游 → 下游 | 现值 | 落进 0.5~2 |
|---|---|---|
| 1 采集工 → 烹饪工 | **0.5 个** | ✅ |
| 1 种植工 → 烹饪工 | **1 个** | ✅ |
| 采集 vs 伐木（金/秒） | **持平（各 0.5 金/秒）** | ✅ |

旧值已废：采集 3.3 个烹饪工、种植 6.7 个、采集是伐木的 6.7 倍（采集 3 秒 10 食材 ≈ 3.3 金/秒 vs 伐木 0.5 金/秒），与**劳动费率 0.5 金/秒**的价格口径冲突。

### 1.3 通用规则

下游工作的**输入速率应当略高于上游的产出速率**，这样上游永远是瓶颈，玩家会主动增加上游工人。

**升级项的显示条件**（v0.0.27）：每份工作的升级项随工作本身解锁，且必须**同时**满足「解锁条件」+「**首次拥有 1 份每种所需资源**」才显示，之后**永久显示**（资源花光也不隐藏）；不满足时不可见，不是置灰。规则出处 → `科技树.md「设计原则」`。

## 三、产出清单与配方

> §2 那一列只是**基数**（跑完一次进度条给多少）。凡是「一次能出多种」或「配方有多个变体」的工作都在本节展开；价格 / 属性 / 完整造价 → `资源表.md「石器时代」~「跨阶段药物、熟食与消费品」`。

### 3.1 A. 产出是「池」的工作（一次出多种）

**#2 采矿** —— 1 矿石，从 **12 种矿**按权重抽。权重表 / 进池科技 / 逐阶段概率 / 概率修改器见 **§4.2**；矿石作为物品的用途与金币 → `资源表.md「矿石」`。

**#3 采集**（v0.0.27）—— 三个项目各产 1 份资源包，资源包按权重随机变成 1 种物品（详见 §4.3）：

| 项目 | 产出包 | 产物池 |
|---|---|---|
| 草地 | 草地资源 ×1 | 植物纤维 90；谷物 / 大豆 / 蔬菜 / 甜菜 / 药草种子 各 2 |
| 平原 | 平原资源 ×1 | 石头 / 木材 / 浆果 / 块根 / 坚果 各 20% |
| 沼泽 | 沼泽资源 ×1 | 野菌 / 药草 各 50%（受伤后永久显示）|

**#4 种植** —— 每个种子一个独立项目：1 种子 → 6 对应作物 + 返还 1 颗对应种子（药草种子 → 6 药草 + 1 药草种子）；草料只由**不消耗**的「干草」项目产出：

| 项目 | 投料 | 收成 | 用途 |
|---|---|---|---|
| 谷物 / 大豆 / 蔬菜 / 甜菜 | 对应种子 ×1 | 对应作物 ×6 + 对应种子 ×1 | 食材 |
| 药草 | 药草种子 ×1 | 药草 ×6 + 药草种子 ×1 | 药材（供 医疗）|

## 十、工作页显示规则

工作页从上到下：技能头（图标 + 名称 + 徽章 + 入驻槽）→ 可用角色头像列表 → 大进度条 → 数值行（周期 / 产出倍率 / 精通）→ 配方卡片 → 升级项卡片。**头像右下角显示该角色当前在做的工作图标，正在做本工作的描边变绿；拖拽是唯一的入驻操作；工作不显示时代。**

**v0.0.30 可见性五条**：

1. **里程碑永久解锁**：伐木 / 采矿 = 曾经拥有 1 木材 + 1 石头；科研 = 曾经攒到基础研究桌 30% 材料；医疗 / 沼泽 = 至少一名角色受伤。条件一旦达成永久保留，资源花光也不回退。
2. **项目门槛（v0.0.30 全工作统一）**：除「采集」外，所有常规工作都必须先买第一个升级项，否则工作页只显示升级项列表；**不再显示「先购买升级项」提示文案**（v0.0.29）。沼泽项目另受受伤里程碑限制；特殊工作（狩猎 / 电力 / 恩赐）不走项目卡。
3. **升级项显示**：已购永久显示；未购的只要科技 / 上一档前置满足，并且**曾经拥有过每种造价资源至少 1 份**（`S.ever`，不是当前持有量）就永久显示。**被动升级项（住房 / 舒适度 / 工事 / 仓库 / 粮仓）使用同一条门槛**。
4. **初始只显示采集**：新档只有采集工作；砍伐 / 采矿 / 科研 / 医疗 / 沼泽都由各自的进度里程碑点亮。
5. **畜牧容量**：畜牧工作不显示固定格数，动物格由「畜牧容量」决定（初始 5，圈舍 +5、大型牧场 +15）。

```
10 个工作全开        10.05 瓦

```

> **这个峰值不含 #防御 的工事耗电**：`被动.md「#防御」` 的 14 项工事合计 **18 瓦** → 工事全开时峰值 **≈ 56.05 瓦**，中期的 3 座风力（45 瓦）就不够了，需要 4 座（60 瓦）或提前上核电站。

### 11.4 供给方案（三选一）

| 方案 | 配置 | 说明 |
|---|---|---|
| 早期 | 4 个电力工人（燃木）| 40 瓦，刚好压住峰值，但占 4 个角色 |
| 中期 | 3 座风力发电机 | 45 瓦，**不占角色**，但要点出 *风力发电 |
| 后期 | 1 座核电站 | 120 瓦，**富余 3 倍**，用来全开所有产线 |

**这就是电力的设计意图**：早期用人力换电，后期用电把自己的角色从电力岗位上换下来。核电站的 120 瓦故意给得远超需求 —— 它的意义不是「够用」，而是「再也不用担心电」。
