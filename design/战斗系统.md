# 战斗系统（照 Melvor 放置的战斗结构）

> **本文件负责**：战斗公式、各时代武器全表、距离与射程、角色战斗属性、离线战斗结算。
> **本文件不负责**：敌人分布 / 数值 / 掉落 → `敌人表.md「区域分布」`、`敌人表.md「普通敌人战斗数值」`；袭击模型与基地战力 → `被动.md「#防御」`；装备造价与仓库格数 → `资源表.md「价格规则」`、`资源表.md「粮仓类与仓库格数」`。
> **公式来源**：Melvor Idle wiki 的 Combat 页实际数值，不是凭印象写的 —— https://wiki.melvoridle.com/w/Combat

---

## 一、定位与边界

### 1.1 战斗只发生在三处

**狩猎（工作 #5）、#黑暗之魂、#模拟纪元。**

- 三处共用同一套角色战斗属性、命中与伤害公式、距离规则。
- 只有 **1v1**（狩猎 / 恩赐怪），没有 PVP / 远征 / 多对多。
- 战斗单位保持「抽象的 Combatant」（**敌人 = 装备为空的 Combatant**），以后要做 PVP 直接复用。

### 1.2 袭击不跑本文件的任何公式

袭击并入 `被动.md「#防御」`，只做「**基地战力 vs 袭击强度**」的纯数值判定 —— 没有战斗界面、不派角色。它复用同一套属性与装备数据，换算口径见 §3.2。

### 1.3 「阶段」是解锁时机，不是出现范围

新阶段解锁新区域，**旧区域永远可访问** —— 回森林猎兔子刷食物永远合法。区域与敌人的完整清单（18 种普通敌人 + 8 只恩赐怪）→ `敌人表.md「区域分布」`。

## 二、战斗是一次自动回合对决

```
狩猎 = 角色 vs 一只敌人
- 双方各有 HP
- 各自按自己的「攻击间隔」行动（不是回合制，是实时时钟）
- 一方 HP ≤ 0 → 战斗结束
- 玩家胜 → 获得肉量 + 皮革 + 图鉴认知度
- 玩家败 → 战斗中断，角色进入「重伤」状态，需要 #医疗；产出按已造成伤害比例折算
```

**关键**：双方攻击间隔不同，所以要按真实时钟模拟，不是简单的"你一下我一下"。

## 三、角色战斗属性（6 个）

| 属性 | 来源 | 作用 |
|---|---|---|
| 生命等级 | 角色自身的战斗属性 | 血量上限 = 100 + 10 × 等级 + 装备 |
| 命中等级 | 角色战斗属性 + 装备命中加成 | 决定命中率 |
| 力量等级 | 角色战斗属性 + 装备力量加成 | 决定最大伤害 |
| 防御等级 | 角色战斗属性 + 装备回避加成 | 决定被命中率 |
| 伤害减免 | 只有装备提供（0~80%） | 按百分比减伤 |
| 攻击间隔 | 武器决定（1.5 ~ 4.0 秒） | 决定出手频率 |

### 3.1 战斗属性是角色级的，与工作精通等级完全无关

**原因：战斗不只发生在狩猎里。** 狩猎 / #黑暗之魂 / #模拟纪元 都用同一套属性，不能由"狩猎精通"驱动，否则只有打猎才能变强。

每个角色独立拥有四项战斗属性（各 1~100 级，各有经验）：

| 属性 | 经验来源 |
|---|---|
| 生命 | 承受伤害 |
| 命中 | 造成伤害 |
| 力量 | 造成伤害（按伤害量）|
| 防御 | 被攻击 |

经验比例照 Melvor：造成伤害 **0.4 XP/伤害**（单一技能）或 0.2 XP/伤害（两个技能分摊）；承受伤害 **0.133 XP/伤害**。

**这意味着**：

- 装备决定「当前战力」，战斗属性决定「这个角色练了多久」
- 新抽到的角色战斗属性从**该角色自己的初始值**起（随机普通角色按 5~12 的随机区间、两位限定英雄按人设 6~14，见 `角色与抽卡.md「卡池角色（2 位英雄 + 随机普通角色）」`），之后必须练
- **装备可以跨角色换，战斗属性不能**
- 换一套好装备立刻变强；练属性需要时间。两条成长轴互不替代

### 3.2 装备与属性 → 战力（供 `被动.md「#防御」` 的袭击判定用）

袭击不跑本文件的任何战斗公式，但复用同一套属性与装备数据。**权威口径在 `被动.md「角色战力与装备战力」`**，这里只留换算式：

```
单角色战力 = (生命 + 命中 + 力量 + 防御) × 3 + 装备战力合计
装备战力   = 伤害减免% × 5 + 力量值 × 2      （防具 / 衣物 / 盾牌）
武器战力   = 力量加成 × 2 + 命中加成 × 1      （主手武器）
```

- 只有**上场角色**（前 X 名，X = 角色上限，由住房从 5 推到 18）计入基地战力；待命队列不计
- **温度 / 护盾值不计战力** —— 它们只服务狩猎与两份恩赐战斗
- 每档"满装一套"的装备战力：石器 **137** / 中世纪 **417** / 工业 **628** / 信息 **978** / 太空 **1,444**（逐件口径与验算见 `被动.md「五档满装基线」`）

## 四、命中公式（Melvor 原版）

```
命中评级 = floor( (命中等级 + 9) × (命中加成 + 64) × (1 + 命中修正/100) )
回避评级 = floor( (防御等级 + 9) × (回避加成 + 64) × (1 + 回避修正/100) )
```

命中率分两支：

```
若 命中评级 < 回避评级：
    命中率 = 命中评级 / (2 × 回避评级)

若 命中评级 ≥ 回避评级：
    命中率 = 1 - 回避评级 / (2 × 命中评级)
```

**性质**：双方评级相等 → 50%。攻击方是防守方 2 倍 → 75%。3 倍 → 83.3%。

**收益递减**：命中评级越高于对方，每点越不值钱。所以堆命中不能无限提升，逼你在"命中/伤害/生存"之间取舍。

## 五、伤害公式（Melvor 原版）

```
基础最大伤害 = floor( 10 × ( 2.2 + 力量等级/10 + (力量等级+17) × 力量加成 / 640 ) )
实际最大伤害 = floor( 基础最大伤害 × (1 + 最大伤害修正/100) ) + 固定最大伤害修正
每次伤害   = 随机(1, 实际最大伤害) × (1 - 目标伤害减免)
```

**验算**（无装备 = 力量加成 0）：

- 力量等级 10 → floor(10 × (2.2 + 1.0)) = **32**
- 力量等级 50 → floor(10 × (2.2 + 5.0)) = **72**
- 力量等级 99 → floor(10 × (2.2 + 9.9)) = **121**
- 力量等级 99 + 力量加成 50 → floor(10 × (2.2 + 9.9 + 116 × 50 / 640)) = **211**

**平均每击伤害 = (最大伤害 + 1) / 2**（因为随机 1~maxHit 均匀分布）

**所以 DPS 公式**：

```
DPS = 命中率 × (最大伤害 + 1) / 2 / 攻击间隔
```

这个公式是配平所有武器的唯一标尺。任何两把武器，先算 DPS 是否接近，再看手感差异。

## 六、距离系统（这就是远程/近战的分野）

**不是给远程加伤害，是给远程买时间。**

```
战斗开始时的距离 = 玩家武器的「射程」
玩家每行动一次，距离 -1（敌人在靠近）
距离 > 0 时：只有玩家能攻击，敌人无法还手
距离 = 0 时：双方正常互殴
```

| 武器 | 射程 | 含义 |
|---|---|---|
| 近战全套 | 0 | 开战即互殴 |
| 矛 | 1 | 白打 1 轮 |
| 短弓 | 2 | 白打 2 轮 |
| 长弓 / 弩 | 3 | 白打 3 轮 |

远程用**更长的攻击间隔**换白打轮数：低 HP 敌人（兔子）近战 1 轮就杀，高 HP 掠食者与重甲敌人则远程更优 —— 形成三方取舍，而不是"远程更强"或"近战更强"。

- 矛的 DPS 最低，但射程 1 换来一次免伤

## 八、角色永远不会死亡

**硬规则：角色永远不会死亡，HP 永远不低于 1。**

```
战斗中 HP 降到「最大生命值的 20%」→ 角色进入「重伤」
- 立即脱离战斗（自动撤退）
- 本次产出 = 全额 × 已造成伤害比例
- HP 继续降到 1 就停住，绝不会更低
- 重伤角色：不产出、不能参战、拖低全局挂机效率
- #医疗 加速回复；HP 回到 20% 以上 → 脱离重伤
```

**数值位置**：

| 参数 | 值 |
|---|---|
| HP 下限 | 1（永远不低） |
| 重伤阈值 | 最大生命值的 20% |
| 脱离阈值 | 最大生命值的 20%（回到即脱离）|
| 自然恢复 | 每天恢复最大生命值的 5% |
| 医疗加速 | 有医疗角色时恢复到 15%/天 |

**时间换算**：**1 天 = 24 秒**（`工作表.md「时间基准」`），所以 5%/天 ≈ 0.21%/秒、15%/天 ≈ 0.63%/秒；满血从 0 自然恢复约 8 分钟，有医疗角色约 2 分 40 秒。

**为什么不让角色死**：角色靠**招募券抽卡**获得（见 `角色与抽卡.md「卡池与角色名单」`），死一个就永久少一个；放置游戏里死亡 = 惩罚离线的玩家。**重伤的代价足够真实**：不产出 + 拖低全局效率 + 要占一个医疗岗位。

**连带影响**：战斗的败北判定不是"HP ≤ 0 判负"，而是"HP ≤ 20% 自动撤退判负"。

## 九、离线结算（这是战斗系统最大的成本）

按真实时钟模拟战斗，一场熊战可能要 30~60 秒、几十个回合。

**每 tick 逐场模拟的代价**：8 小时 = 28,800 秒，平均每场 20 秒 → 1,440 场 × 每场 30 回合 = 43,200 次结算。可接受，但比伐木贵几个数量级。

**离线用期望值结算**：

```
离线时不做逐回合模拟，直接算：
  本次狩猎期望时长 = 敌人HP / (玩家DPS × 命中率)
  离线产出 = 离线秒数 / 期望时长 × 单次产出 × 胜率
  胜率 < 100% 时按概率扣掉败北场次，并从产出里扣除
```

**成本 O(1)**，误差在可接受范围。在线时才跑完整回合模拟（因为玩家要看到战斗过程）。

**这条规则适用于所有"有状态"的系统**：在线逐帧、离线用期望值。

### 9.1 实现约定（v0.0.11）

```
离开判定：存档里 lastSave → 现实秒；< 60 秒不结算（交给正常 tick 小步追帧）
结算上限：8 小时（away > cap 时按 cap 算，弹窗注明）
生产推进：15 秒一个时间块，循环到用完（同 tick 顺序：食物 → 生产 → 木易天二人一 → 回血）
精通：非战斗工作每个时间块都走 gainMastery，升级立刻计入下一块的 jobSpeed 与精通经验；
      战斗按总击杀一次补 4×击杀（不再反馈回本次结算，误差 <5%）
战斗结算：O(1) 期望值，不逐回合
  击杀时长 tKill = max(一次攻击间隔, 敌人 HP ÷ 玩家 DPS)（charDps 已含命中率 / 目标减伤 / 攻速）
  胜率 pWin = tKill ≤ 被打进重伤时长 tInjure ? 1 : tInjure ÷ tKill
  击杀期望 = 时间 ÷ (tKill + 3 秒刷新) × pWin；掉落把 chance / min / max 折成期望值
  血量损耗：挨打速率 = Σ(击杀速率 × 单杀挨伤)，与自然恢复相减；净掉血时
    能撑时长 = (当前 HP − 20% 上限) ÷ 净掉血速率，撑不满就先判重伤、只结算撑住的那段
  任一怪 pWin < 1 或血量撑不满 → 本次离线判「重伤」，产出只保留打赢的部分
袭击补算：离线期间每 2 小时的判定照常触发，最多补 12 次（之后把下一次顺延到当前时间 + 2h）
```

**精通等级会不会算进来**：会。生产走的还是同一个 `produceJob → gainMastery` 循环，每 15 秒块重新取一次 `jobSpeed`，所以「精通升级 → 下一块变快」在离线里同样成立；实测离线 1 小时伐木精通 36 级 / 1918 XP，在线同条件 36 级 / 1922 XP（差 0.2%，来自时间块粒度）。

**为什么不用逐场模拟**：8 小时 ≈ 1,440 场 × 30 回合，比生产贵几个数量级；期望值误差来自随机掉落，量级 < 1%，不影响放置体验（`design/战斗系统.md` 本节即权威）。

### 10.6 火器与近战的分野

- **为什么太空武器也吃精密零件**：让信息时代的中间品（精密零件）活到终局，否则玩家造完信息装备，精密装配这份工作就没事干了（`README.md「数值设计的四条原则」` 原则 3 加强版）。
- **火器改变了射程的天花板**：冷兵器射程上限 3，火器 4~6。工业时代后射程与伤害同时提升。
- 近战与火器的差异**只靠破甲 / 射程 / 命中 / 攻击间隔**这四件事体现。**v0.0.30：武器不再有「特性」文字**，`WEAPON_COMBAT.special` 与面板的「特性：…」行已删除，数值全部以面板行为准。
- **护盾腰带**目前只是普通副手防具，不提供「免疫远程」—— 那个效果留给以后的 PVP。

### 10.7 武器与护甲占仓库格

- 每把武器、每件护甲占用 **1 个仓库格**（和普通物品一样）。没有独立的装备库。
- **双手武器占主手且占用副手**（v0.0.17 起）：装备双手武器时，副手装备自动退回仓库；主手是双手武器时，装备副手会把双手武器退回仓库。角色页的副手槽会**半透明显示当前双手武器**表示被占用，点击仍可打开副手列表换装。全身 **12 栏** = 头盔 / 内衬头盔 / 胸甲 / 内衬 / 护腿 / 内衬护腿 / 靴子 / 袜子 / 副手 / 项链 / 腰带 / 主手，其中主手与副手互斥（1H + 副手，或 2H 单独）。
  `被动.md「五档满装基线」`按 **1H + 盾** 的满装口径计算；双手武器少掉的盾战力由更高的武器力量补偿，`一键最优` 会按「主手 + 副手合计战力」自动比较，不会盲目选双手。
- **终局仓库格数 224 格**（见 `资源表.md「粮仓类与仓库格数」`）。
