**验算参考**（角色开局：命中 10 / 力量 10 / 防御 10 / HP 100 / 无防具 / 短剑 2.0 秒，命中加成 +12）

- 最大伤害 = floor(10 × (2.2 + 1.0)) = **32** → 平均每击 (32+1)/2 = **16.5**
- 命中评级 = (命中等级 + 9) × (命中加成 + 64) = 19 × 76 = **1,444**；不拿武器 = 19 × 64 = 1,216
- 打兔子（防御 1）：回避评级 (1+9) × 64 = **640** < 1,444 → 命中率 1 − 640/(2×1,444) ≈ **78%** → **1 轮击杀**
- 打熊（防御 15）：回避评级 (15+9) × 64 = **1,536** > 1,444 → 命中率 1,444/(2×1,536) ≈ **47%**
  - 每轮期望 16.5 × 0.47 ≈ **7.8** 伤害 → 需 **23 轮**
  - 熊 maxHit = floor(10 × (2.2 + 4.5)) = **67**，对玩家命中率 ≈ **22%**（熊评级 (35+9)×64 = 2,816 vs 玩家 1,216）→ 约 **7 轮**打空玩家 HP 100
  - 结论：**开局不该打熊**

**掉落：随机资源（不新增物品）**

| 敌人 | 掉落次数 | 说明 |
|---|---|---|
| 游荡僵尸 | ×2~4 | 每次从**已解锁材料池**抽 1 种材料 |
| 尸群 | ×4~7 | 同上 |
| 变异体 | ×7~12 | 同上 |
| 尸潮首领 | ×12~20 | 同上 |

**抽取规则（写死）**：`权重 = 1 / 该材料的单价`

- **越便宜的材料越容易抽到** → 每次掉落的**期望金币价值恒定**，它因此是「补缺口」的万能农场，**不是印钞机**
- 只从**已解锁**的材料池里抽（不给你还没解锁时代的东西）
- 产出不可控 → 与其他采集工作不重叠

## 五、掉落物规则

### 5.1 肉类：按动物拆分（v0.0.38）

**每种动物掉自己的肉**：兔子 → 兔肉、松鸡 → 松鸡肉、鹿 → 鹿肉、野山羊 → 山羊肉、羚羊 → 羚羊肉、野猪 → 野猪肉、狼 → 狼肉、鳄鱼 → 鳄鱼肉、巨蜥 → 巨蜥肉、熊 → 熊肉、驼鹿 → 驼鹿肉、野牛 → 野牛肉、犀牛 → 犀牛肉、猛犸 → 猛犸肉、变异巨兽 → 变异巨兽肉、外星掠食者 → 外星掠食者肉；机械兽 / 硅基生物仍不掉肉。畜牧产出同步使用各自肉名。

**为什么改**：烹饪与「肉食食材」筛选需要按标签取料；不同肉名让玩家能看出自己养的是什么动物，同时保留原本的肉量差异。所有肉都带 `肉食` 标签，烹饪的「肉食食材」列表由标签自动生成，16 种肉不会让配方数量爆炸。

敌人的差异由三个维度承担：

| 维度 | 跨度 |
|---|---|
| 肉量 | 2（兔子）→ 80（外星掠食者）|
| 战斗难度 | HP 10 → 600，伤害减免 0% → 55% |
| 独有皮革 | 0 → 4 种 |

### 5.2 皮革：3 档通用 + 4 种独有 + 羽毛 = 8 种

**皮革的用途分级 —— 做不同等级的装备**，所以皮革分档有意义，肉不分档。

| 皮革 | 来源 | 用途 |
|---|---|---|
| 小型皮革 | 兔子 | 低级衣物、内衬 |
| 中型皮革 | 山羊、鹿、野猪、羚羊 | 中级护甲、衣物 |
| 厚重皮革 | 猛犸、驼鹿、野牛、巨蜥、犀牛、变异巨兽 | 高级护甲 |
| 羽毛 | 松鸡 | 箭矢、枕头、装饰 |
| 狼皮 | 狼 | 高级衣物（保暖）|
| 熊皮 | 熊 | 高级护甲 |
| 鳄鱼皮 | 鳄鱼 | 高级护甲（轻）|
| 外星皮革 | 外星掠食者 | 顶级护甲 |

> **v0.0.40**：上表 7 种皮革都带 `皮革` 标签（物品面板不再显示「动物产物」分类），并带隐藏 `tint` 与 `leatherMods`；皮帽 / 皮甲 / 皮裤 / 皮靴 / 皮带按「皮革」标签投料，成品按实际消耗皮革换色并修正战斗数值。

## 六、图鉴认知度

- 每次成功狩猎累积该敌人的**图鉴认知度**
- 认知度满 → 该敌人解锁**畜牧线**，可以圈养（不用再冒险狩猎）
- 认知度每级给对该敌人的 **+2% 伤害**（打得更快 = 更少挨打 = 更低重伤风险）
- 认知度是**狩猎解锁畜牧的唯一路径**
- **恩赐怪（黑魂怪 / 模拟纪元怪）不进图鉴、不能畜牧** —— 它们只能打
- **畜牧体型（v0.0.30）**：极小 0.5（兔子 / 松鸡）｜小 1（鹿 / 野山羊 / 羚羊）｜中 2（野猪 / 狼 / 鳄鱼 / 巨蜥）｜大 3（熊 / 驼鹿 / 野牛 / 犀牛）｜极大 5（猛犸 / 变异巨兽 / 外星掠食者）；机械兽、硅基生物**不能畜牧**。每只动物的消耗 / 周期 / 产出见 `工作表.md「4.6 畜牧」`。

## 八、待定

- **区域敌人刷新规则** —— 每个区域有**固定敌人池**；进入区域后随机抽 **1 只**；击杀后 **3 秒**刷下一只；区域按时代开放
