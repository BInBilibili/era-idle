## 操作

1. 开局只有 **采集**：把玩家拖到「平原」项目上，攒出 1 木材 + 1 石头；之后伐木 / 采矿永久出现，先买石斧 / 石镐才会出现对应项目。**其它工作同理：先买第一个升级项，项目才会出现**（v0.0.30）。
2. **科研** 需要先攒到基础研究桌 30% 材料，再买基础研究桌，科研项目才会出现；科研点用于下方科技树。
3. **仓库** 里点「卖 1 / 全卖」换金币；**商店** 用金币买材料、招募券、技能书。
4. **招募** 用 10 张招募券抽一次（限定 / 常驻两池；第 1 抽必出角色，之后窗口 2→10 抽）→ 送礼提升好感 → 好感 50 解锁角色特技工作；招募券还能从**图鉴首次收录**领取（物品 1 / 敌人 3 / 角色 5）。
5. **角色** 页拖装备、拖拽角色列表决定上场顺位（第 X+1 名起自动置灰）；**补给栏**点食物 / 医物槽打开下拉列表，选中该角色优先消耗的种类。
6. **狩猎** 选区域派角色自动打怪，掉落皮革/食材，涨战斗属性和图鉴认知度；第一次受伤会永久解锁医疗与沼泽。**狩猎页看敌我血条、攻击间隔条与伤害日志**；认知度满 100 的动物可在**畜牧**里圈养（先买圈舍，再点末尾的大＋）。
7. **后门**：网址加 `?dev=1`，或连点左上角版本号 5 次，开启开发者模式（右上角 🛠 / 设置里打开调试面板）；也可在控制台用 `DEV.on()` / `DEV.off()` / `DEV.open()`。

> **1 游戏日 = 24 现实秒**（1 秒 = 1 小时）；挂机时每 200ms 一跳。离开 ≥ 60 秒（关页面 / 切后台 / 电脑休眠）回来，按真实离开时间**一次结算离线收益**，上限 8 小时；不足 60 秒按 0.2 秒小步追帧。
>
> 只有「回血」按天结算：自然 5%/天 ≈ 0.21%/秒，有医疗角色 15%/天。工作、科研、精通、食物、电力、战斗、商店、粮仓腐坏、袭击仍按真实秒，数值不变。

## 目录结构

```
index.html            入口
css/style.css         全部样式（深色 Melvor 风，响应式，窄屏自然降级为单列）

js/data/jobs.js       33 份工作（周期 / 配方 / 升级项 / 矿区权重 / 发电机）
js/data/techs.js      42 项科技（时代 / 前置 / 花费 / 解锁）
js/data/enemies.js    26 种敌人 + 8 区域 + 29 把武器战斗数据
js/data/passives.js   住房 / 舒适度 / 工事 / 仓库 / 粮仓档位与常数值
js/engine.js          状态机：产出、精通、战斗、抽卡、商店、袭击、存档
js/ui.js              所有页面渲染（工作页 / 角色页 / 科技 / 商店 / 图鉴 / 招募 / 被动）
js/icons.js           程序化图标库：215 件物品 + 26 种敌人的内联 SVG（Melvor 风三阶平涂）
js/app.js             启动、路由、拖拽、弹窗、存档按钮
design/               原始设计文档（8 份 Markdown，游戏数值的唯一权威来源）
tools/test.js         无头冒烟测试（node tools/test.js）
tools/icon-sheet.html 图标总览（浏览器打开，?from=0&to=60 或 ?ids=stone,… 切片校对）
tools/icon-shot.mjs   图标总览截图（node tools/icon-shot.mjs <from> <to> [out.png]）
tools/shot-ui.mjs     真实页面截图（node tools/shot-ui.mjs warehouse job:hunting codex#enemies）
```
